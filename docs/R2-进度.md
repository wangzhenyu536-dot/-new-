## 暂定模板与校验

单个 .xlsx 数据工作表，首行严格为 `timestamp_ms`、`value`，至少两个采样点。时间为非负、严格递增的实际毫秒值，可不等间隔；幅值允许负数和零，必须是有限原始数值。没有假设 μV、512 Hz，没有插值、排序、补值或丢弃异常数据。

校验错误附带文件、工作表、行、列和原因。拒绝缺列、额外数据列、数值字符串、空值、重复／乱序时间、负时间、公式（包括含缓存数值的公式）、合并／隐藏数据、多个工作表及损坏文件。内部空行拒绝；尾部纯格式空单元不计入数据。

集中暂定预算：标题 160 字符，分类 60 字符，文本 100,000 字符／1 MiB，Excel 5 MiB、展开 25 MiB、ZIP 1,000 项、50,000 个采样点、解析 5 秒。ZIP 在流式解压时限制展开量，验证结构和 CRC，XML 拒绝实体声明。浏览器通过 Worker 解析并硬性超时终止；Node 共用同一纯校验模块，R3 复验将复用它。基础波形按真实时间位置绘制；大序列仅显示最小／最大值包络，保留原始样本。交互与性能验收仍在 R6。

## 验收入口与样例

页面：http://127.0.0.1:5173/packs/new 。已有前端和默认模拟器保持运行，无需重复启动。普通成员 `member@evertrace.test`，密码 `EvertraceDemo2026!`；也可用自己的本地注册账户。

1. 填标题，选择已准备的 `Synthetic practice` 分类，或输入新分类并点击添加。另一个已登录成员可看见同一分类；大小写、全半角和空白规范化后的同名会选中已有分类。
2. 填正文，或选择非空 UTF-8 .txt；点击页面“下载合成 Excel 示例”，再选择该文件，会出现三点基础波形。点击“检查材料”显示本地检查通过。
3. 下载并选择“错误合成示例”，会显示 `EEG` 工作表第 3 行 `value` 空值错误。移除 Excel、清空标题或正文可检查必填提示。可切换中英文和手机尺寸。

可下载样例也在 `apps/web/public/samples/`；更多边界样例与合成文本在 `outputs/R2/samples/`，可由 `npm run fixtures` 重建。样例全为生成数据，没有真实脑电资料。验收只需操作页面，不需运行测试。
