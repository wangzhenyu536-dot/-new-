## 本轮范围

需求 AUTH-01～04、AUTH-12、UI-02 的本地实现：邮箱密码注册／登录、退出、密码重置请求、普通成员档案、登录返回目标、后台首位管理员初始化与角色路由。注册无需审批，没有管理员自选项。

账户使用 Firebase SDK 与本地 Authentication，不使用自建密码表或假登录。会话使用 SDK 的当前标签页 session persistence，刷新可继续，退出后再次进入业务页需登录。首页始终公开；默认英文，已保存的手动语言继续生效。

`ensureProfile` 只根据已验证的登录身份与 Admin Auth 用户资料创建档案，忽略客户端 uid／email／role。事务保证初始化幂等；已有管理员不会被再次初始化降级。仅本人可读取自己的档案，客户端写入和成员列表继续拒绝。创建、浏览入口目前明确展示 R2／R3 的待开发内容，不提供假资料。

首位管理员脚本仅连接本地 demo 项目，事务同时保护 role 与 adminCount，并发两个候选只有一个成功；相同管理员重复初始化不变更。管理员成员页目前是权限正确的占位页，实际管理与最后管理员保护在 R8。
