# Spark S3：编辑、查找与导出

日期：2026-10-06。S2 已由用户验收通过，本轮按 [Spark 开发计划](Spark-开发计划.md) 实施 S3。414 项实际自动测试及类型、静态检查、前端构建全部通过，用户已验收通过，S4 已授权。

## 本轮能力

- 创建者编辑自己的技能包，管理员编辑全部；其他成员可以查看和下载，不能通过直接编辑网址越权。
- 修改标题、正文和分类；保留、新增、逐件替换或移除 TXT、Excel、图片。每件 512 KiB、合计 3 MiB、最多 12 件，正文或有效 TXT 至少有其一，至少一份有效 Excel，原字节及无单位原始数据继续保留。
- 原件实际读取后预览和校验，再用同一事务更新父记录、两组清单和全部当前原件，精确清理已移除的剩余槽。作者、作者名、创建时间不变，版本递增；失败保留整份旧版和当前表单。准备阶段可取消，原子提交开始后取消停用。
- 过期编辑明确提示冲突，保留未保存输入，用户点击“重新加载最新版本”才放弃表单并加载新版。确认响应丢失时检查版本和本次内容指纹，已经保存的编辑只确认一次，避免重复递增或误当成新的保存。
- 列表支持标题前缀、分类、全部／我的资料组合筛选，筛选保存到网址，刷新和登录返回后保留。标题查询忽略字母大小写、统一全角兼容字符；默认按新建时间排序，前缀查询按标题排序，两者都用文档 ID 补足稳定顺序。每页 12 件，上页／下页使用游标；翻页失败保留当前页，重试目标仍是原本请求的页。
- 详情支持原件、单份 Excel 波形 PNG 和完整 ZIP。PNG 为 2400×1000，始终覆盖该 Excel 的完整时间范围，页面缩放不影响导出；仅为显示保留极值抽样，精确数据仍在原 Excel。
- ZIP 包括全部当前原件、正文、README、manifest 及每份 Excel 对应的 PNG。重名附件分别保存，路径安全；README 和 PNG 标注随当前语言变化，原文件和原文不翻译、不压缩改写。
- 读取核对版本、清单、长度和 SHA-256；导出前后再次核对版本。文件缺失／损坏、PNG 编码失败、导出取消或版本变化都不会下载残缺 ZIP；异常提供重试或重新加载。

保持官方 Firebase SDK、规则及数据合同本地／云共用，Spark 操作只连接 Auth 和 Firestore。格式与内容预检在浏览器执行；规则验证身份、容量、结构与原子一致性，不宣称后台复验内容。默认英文、记忆语言选择、社区术语、手机双语及此前技能包标题字号约定保持。
