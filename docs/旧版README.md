# 拾光：人类智慧经验采集 Agent

这是一个可运行的完整本地网站与 Agent 原型。网站采用黑白编辑式视觉，从加载序章进入可随鼠标移动的“人类智慧档案墙”，并整合注册、经验讲述、最多三次温和追问、多模态资料上传、智慧包审阅确认和本地归档。

## 最简单的启动方式

1. 双击 `start-evertrace.command`。
2. 浏览器会自动打开 `http://127.0.0.1:8765`。
3. 浏览官网后进入页面中的 `WISDOM STUDIO`。
4. 输入一段经历，按页面提示完成最多三次轻访谈。
5. 生成智慧包草稿，检查后点击确认归档。

生成的经验包保存在 `data/packages/`。

## 启用真正的 AI

未配置 API Key 时，程序自动使用演示模式，仍可完整体验三问和归档流程。

启用 AI：

1. 准备 OpenAI API Key。
2. 双击 `configure-ai.command`，粘贴 Key 并回车。
3. 重新启动“拾光”。

Key 只保存在本机 `.env` 文件中。不要把 `.env` 发给别人。

## 已实现

- 自由讲述与动态 AI 追问
- 黑白高级感完整官网与响应式移动端
- 加载序章和鼠标驱动的人物智慧档案墙
- 三步注册与渐进显色体验
- 程序层硬限制最多三次追问
- 跳过和提前结束
- SQLite 本地会话保存
- 中断后数据仍在数据库中
- 图片、音频、CSV、JSON证据上传
- Markdown、JSON、对话记录、知识图谱候选归档
- 智慧包先审阅、确认后才正式归档
- 无 API Key 演示模式
- 用户自述、事实和推断分离
- 生理信号只作为描述性元数据

## 数据位置

- 会话数据库：`data/wisdom.db`
- 上传证据：`data/uploads/`
- 经验包：`data/packages/`

所有内容默认保存在本机。删除前请先备份。

## 隐私和安全

- 本项目不是医疗设备，不提供诊断。
- 不允许根据 EEG、EMG、面部或声音断言具体情绪、思想、人格或意图。
- 原始生理数据默认不进入公开传播版本。
- 经验包发布前应由本人确认并删除第三方身份信息。
- 佩戴电极采集时应使用电池供电，不要同时连接市电充电器。
