- 独立 `firebase.spark.cloud.json`，只含 Firestore 正式规则／索引和静态 Hosting，页面直接访问及刷新使用 SPA 重写，静态文件按哈希缓存。
- `cloud:spark:prepare`／`cloud:spark:deploy` 明确要求同一真实项目、Spark 后端和关闭模拟器；仅转交六项公开 Web 配置，不要求 Storage bucket、Functions 区域或服务账号密钥。错误项目、缺配置、模拟器变量及不合法 Auth 域名在构建／发布前拒绝。
- 生产构建使用专用 Spark 路由／账户装配入口，仍复用现有业务页面、官方 Auth／Firestore SDK、事务、数据合同和规则。提取共用页面框架，原预览保留；依赖图检查发现 Storage／Functions／旧路由模块即拒绝发布，不只是隐藏入口。
- `spark-cloud` 构建不连接模拟器；`spark-test` 仅允许固定独立 demo 测试项目、Auth 29099／Firestore 28090。两者使用同一专用路由，测试配置不得用于真实云项目。

- 已按用户提供的 `wisdom-a9e09` Web 配置生成 `apps/web/dist-spark`，首页初始 JavaScript **378,771 字节**，低于 500 KiB；上传、下载和 SDK 按需加载。完整 SDK 懒加载块超过 500 kB 的构建提醒已保留，不把它误称为初始首页超过限制。
