# R7 删除与分类管理

日期：2026-10-05。状态：**验收通过（含创建者删除权限修订）**。用户已验收 R6 及主页管理入口并授权本轮。

## 本轮交付

- DELETE-01～02：创建者可删除自己的、管理员可删除全部，在技能包详情操作，先打开确认对话框，再勾选不可撤销说明并确认。未勾选时不能提交；取消保留全部资料。服务端重新检查成员身份、创建者归属或管理员权限、资料版本和进行中的保存，随后以 deleting 状态关闭资料及原件访问。没有回收站或恢复操作。
- 清理正式原件、失去引用的正式副本、关联暂存对象、全部有效／无效附件文档、上传会话及旧清理记录，最终删除主记录并原子更新分类计数。按对象 generation 设置删除条件，缺失对象视为已清理；其他错误停止完成提交。
- 清理失败或批次尚未完成时保留 pending 操作，创建者在资料列表看到自己的、管理员在资料列表或分类管理页看到全部“待完成操作／继续清理”。重试复用 operationId，重复和并发调用不会重复减计数或误报成功。原先编辑遗留的附件清理也可在详情精确重试，保留当前有效原件。
- 删除后保留不含正文或附件的最小请求标记和操作结果，防止重放旧上传请求重新创建同一个包；这些记录不能恢复资料，客户端不能直接写入。
- CAT-04：分类管理页可重命名；名称规范化、唯一索引和显示名称事务同步，规范化同名拒绝，旧名称可重新用于新分类。重命名不修改附件路径。
- CAT-06：使用中的分类删除前必须选择不同且有效的目标。迁移锁住源分类及目标管理操作，阻止向源分类保存；目标仍允许普通保存，计数以事务更新。只迁移分类引用并增加版本，保留创建者、标题、正文和全部附件原字节。完成后复查无源引用，删除源分类及名称索引；空分类可直接删除。
- 长任务采用有锁、可重试批次。分类每批最多 75 个引用；关联会话和附件分批清理，存储每次按有限对象数处理，单次操作在约 80 秒预算内留下可续进度。活跃操作有 3 分钟租约；中断后租约到期可继续。每个关键事务和存储删除阶段复核成员身份及归属／管理员权限。角色管理功能仍在 R8。
- 管理入口：管理员资料列表增加“Manage categories／分类管理”；普通成员在自己的技能包有整体删除按钮，可读取自己的删除进度；不能删除他人的、进入分类管理或读取他人的／分类内部操作。Firestore 客户端直接删除／写业务和角色仍被拒绝，Storage 原权限继续按 ready 状态及附件访问表保护；未放宽原权限。
- 全部操作、进度、错误、确认和重试提供英文／中文，手机可操作；管理页登录后返回路径已支持 /admin/categories。
